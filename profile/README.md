## 关于我们

**CWNU Open-Source Community（西华师范大学开源社区）** 是由学生自主发起和维护的非官方开源技术社区。

我们相信，技术的价值不仅在于学习和掌握，更在于创造、分享与持续改进。

社区以真实项目为起点，以开源协作为纽带，致力于构建开放、平等、互助的开发者协作环境，推动校园技术成果从个人实践走向公共贡献。

我们主要关注三个方向：

- **软件工程与 AI**：探索 AI 智能体、开发者工具与现代软件工程实践，打造真正解决问题的开源软件。
- **算法竞赛与学术实践**：建设面向 XCPC 竞赛、算法训练与学术交流的工具链、评测平台和技术模板。
- **开放知识与基础设施**：整理可复用的学习资源、工程经验与校园知识，推动信息共享和知识的长期维护。

我们鼓励实验，也尊重工程严谨性；重视创新，也重视文档、测试和可维护性。

## 参与贡献

开源不仅属于经验丰富的开发者，也属于每一位愿意学习、分享和实践的同学。

无论你是第一次接触 Git 和 GitHub，还是已经有独立开发经验，都欢迎参与社区建设。

**你可以从以下方式开始：**

1. **参与项目开发**：选择感兴趣的仓库，阅读项目文档，通过 Issue 或 Pull Request 提交改进。
2. **完善文档与知识库**：修正错误、整理教程、补充使用案例，让更多人能够轻松使用开源成果。
3. **报告问题与分享想法**：反馈 Bug、提出功能需求，或参与技术方案讨论。
4. **发起新的开源项目**：分享值得长期维护的工具、课程实践或创新项目，与社区共同建设。

每一次有价值的贡献，无论大小，都值得尊重。

## 社区原则

我们坚持开放协作、技术平等和尊重贡献者的社区文化。

- **开放**：鼓励知识共享、技术交流与跨项目协作。
- **务实**：重视真实需求、实现质量和可验证的成果。
- **包容**：尊重不同经验水平、技术背景和观点的贡献者。
- **可持续**：鼓励完善文档、自动化测试和维护流程，让项目能够长期发展。
